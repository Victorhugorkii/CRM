# CRM — NeverX

A CRM (Customer Relationship Manager) frontend built with React 19 + TypeScript + Vite.

## Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **UI Components**: Radix UI + shadcn-style components
- **State**: Zustand
- **Data Fetching**: TanStack Query
- **Forms**: React Hook Form + Zod
- **Routing**: React Router v7
- **Charts**: Recharts
- **Drag & Drop**: dnd-kit
- **Animations**: Framer Motion

## Running
```bash
cd CRM && npm run dev
```
Dev server runs on port 5000. The "Start application" workflow handles this automatically.

## Project layout
All source code lives in `CRM/src/`. Features are organized under `src/features/` (auth, clients, dashboard).
